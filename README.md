## About

**DriveWise** is a mobile app built with **React Native**, **Expo**, and **TypeScript** that helps users calculate and compare the Total Cost of Ownership (TCO) for vehicles. It pulls real vehicle data from the free NHTSA and CarQuery APIs and uses **Zustand** for state management to deliver personalized car recommendations and side-by-side cost comparisons.

## Features

- TCO calculator covering depreciation, fuel, insurance, maintenance, and taxes
- Real vehicle make and model data fetched from the NHTSA and CarQuery APIs — no API key required
- Side-by-side car comparison for up to two vehicles
- Depreciation explorer showing projected vehicle value over time
- Personalized car recommendations based on saved user profile and driving habits
- Smart alerts for price changes and maintenance reminders
- Persistent user preferences stored with AsyncStorage

## Technology Stack

- **Mobile**: React Native, Expo, TypeScript
- **State Management**: Zustand
- **Data Sources**: NHTSA API, CarQuery API
- **Storage**: AsyncStorage
